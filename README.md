# 🔐 Spring Security Template

Uma base pronta para projetos **Java + Spring Boot** com autenticação e autorização utilizando **Spring Security**. O objetivo deste projeto é acelerar o desenvolvimento de APIs REST, fornecendo uma estrutura organizada, segura e de fácil manutenção.

---

## 🚀 Tecnologias

- Java
- Spring Boot
- Spring Security
- Spring Data JPA
- Maven
- JWT
- Hibernate
- MySQL / PostgreSQL
- Docker (opcional)

---

## ✨ Recursos

- 🔐 Autenticação com JWT
- 👤 Cadastro e login de usuários
- 🛡️ Autorização baseada em Roles
- 🔑 Senhas criptografadas com BCrypt
- 🚫 Tratamento de exceções
- 📦 Estrutura organizada em camadas
- ✅ Validações com Bean Validation
- 📄 API REST

---

## 📂 Estrutura

```
src
├── config
├── controller
├── dto
├── entity
├── exception
├── repository
├── security
├── service
└── util
```

---

## 🎯 Objetivo

Este projeto foi desenvolvido para servir como um **template reutilizável**, permitindo iniciar novas aplicações Spring Boot sem precisar configurar toda a infraestrutura de segurança do zero.

---

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/Thy281/Spring-Security-Template.git
```

Entre na pasta:

```bash
cd Spring-Security-Template
```

Execute a aplicação:

```bash
./mvnw spring-boot:run
```

Ou

```bash
mvn spring-boot:run
```
